# Simlet 品牌资源

图标讲的是这个应用在干的事：**一张 SIM 卡，被钉到了别的国家。**

左上那道斜切角是 SIM 的身份（没有斜切角它就只是一张纸），中间那颗图钉是「位置」。两个形状、三种颜色，缩到 40px 还认得出来——这是它能直接当 QQ 头像用的原因。

## 文件

| 文件 | 用途 |
| --- | --- |
| `svg/simlet-icon.svg` | 主图标：绿底方角，白卡黑钉。仓库展示、应用商店、文档首页 |
| `svg/simlet-icon-dark.svg` | 深色底：墨底绿卡。深色桌面、深色聊天列表、暗色海报 |
| `svg/simlet-avatar.svg` | 圆形满幅：**QQ / 微信 / GitHub 头像用这一张**，方底被裁成圆会缺角 |
| `svg/simlet-mark.svg` | 纯图形，透明底。嵌在别的版面里用 |
| `svg/simlet-icon-mono.svg` | 单色（`currentColor`）。印刷、蚀刻、水印，以及启动器的「主题图标」层 |
| `png/simlet-{512,256,180,96,48}.png` | 主图标的位图导出，48/96 可直接当 favicon |
| `png/simlet-{dark,avatar,mark,mono}-512.png` | 各版本的位图 |

位图全部由 `python tools/gen-brand.py` 从 SVG 重新生成，**别手改 PNG**。

## 几何

画布 512×512，图形写在 240×280 的卡上、居中于 (256,256)，再整体放大 1.15 撑满底。

- 卡：`x 136..376`、`y 116..396`，圆角 26，左上 76 斜切（斜切两端各倒 10 圆角，别留尖角）
- 图钉：圆心 `(256,233)`、半径 54，尖端 `(256,333)`；两条边与圆相切，切点 `x 210.5 / 301.5`
- 钉孔：`(256,233)`，半径 20

单色版是**一条路径 + `fill-rule="evenodd"`**：卡实、钉镂空、钉孔又实。拆成三个同色 path 会全部涂成一个颜色，图钉就没了。

Android 启动图标复用同一批路径：`app/src/main/res/drawable/ic_launcher_foreground.xml` 里用 `<group>` 把 512 画布缩到 108 自适应画布，缩放系数 `0.1746 = 32.2 / 184.4`（184.4 是卡角到中心的距离，32.2 留在 66dp 可见圆内）。**改形状要两边一起改**，别在启动图标里另画一套。

## 颜色

| 角色 | 色值 | 来源 |
| --- | --- | --- |
| 品牌绿（主底 / 深色版卡） | `#699973` / `#89CC97` | 应用内强调色 `AccentLight` / `AccentDark` |
| 卡白 | `#FCFCFC` | 应用内 `SurfaceLight` |
| 墨（图钉 / 深色版底） | `#131313` | 应用内 `TextPrimaryLight` |

绿底 + 白卡 + 墨钉是固定搭配，不要换成语义不同的第三种颜色。需要单色时走 `simlet-icon-mono.svg`，用 `currentColor` 涂。

## 红线

- 不加投影、渐变、描边、圆角外发光——这三层形状本身就够了
- 不拉伸、不斜切、不给图钉换形状；只允许整体等比缩放
- 主图标四周留白不小于卡宽的 18%；嫌挤就用 `simlet-avatar.svg`，别自己裁
- 别把卡画成正方形：斜切角是这张图唯一的「这是 SIM」的线索
