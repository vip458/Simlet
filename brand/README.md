# Simlet 品牌资源

图标讲的是这个应用在干的事：**一张 SIM 卡，内容被改写。**

左上那道斜切角是 SIM 的身份（没有斜切角它就只是一张白卡片），卡心一上一下两条反向箭头是「覆盖、改写」——国家码和运营商名都是盖掉系统读到的那份配置，不动卡本身。两个形状、三种颜色，缩到 40px 还认得出来，这是它能直接当 QQ 头像用的原因。

> 第一版在卡心放的是定位图钉，一眼被读成地图/定位软件——图钉是个比 SIM 强得多的符号，语义会被抢走。所以这里宁可少一点抓眼，也不留错类别。

## 文件

| 文件 | 用途 |
| --- | --- |
| `svg/simlet-icon.svg` | 主图标：绿底方角，白卡墨箭头。仓库展示、应用商店、文档首页 |
| `svg/simlet-icon-dark.svg` | 深色底：墨底绿卡。深色桌面、深色聊天列表、暗色海报 |
| `svg/simlet-avatar.svg` | 圆形满幅：**QQ / 微信 / GitHub 头像用这一张**，方底被裁成圆会缺角 |
| `svg/simlet-mark.svg` | 纯图形，透明底。嵌在别的版面里用 |
| `svg/simlet-icon-mono.svg` | 单色（`currentColor`）。印刷、蚀刻、水印，以及启动器的「主题图标」层 |
| `png/simlet-{512,256,180,96,48}.png` | 主图标的位图导出，48/96 可直接当 favicon |
| `png/simlet-{dark,avatar,mark,mono}-512.png` | 各版本的位图 |

位图全部由 `python tools/gen-brand.py` 从 SVG 重新生成，**别手改 PNG**。

## 几何

画布 512×512，图形写在 240×280 的卡上、居中于 (256,256)，再整体放大 1.15 撑满底（圆底头像版放大 1.26）。

- 卡：`x 136..376`、`y 116..396`，圆角 26，左上 76 斜切（斜切两端各倒 10 圆角，别留尖角）
- 箭头：26 描边、圆帽圆角。上条水平 `y=228`、`x 200..312`，箭头尖朝右；下条水平 `y=290`、`x 200..312`，箭头尖朝左。两条错开半个身位，中间留 36 的空隙

单色版是**一条路径 + `fill-rule="evenodd"`**：卡实、两条箭头镂空。这里箭头必须写成实心多边形（镂空只能镂空填充形状，描边进不了 evenOdd），所以杆端补了 13 的圆帽、箭头尖保留直角。

Android 启动图标复用同一批路径：`app/src/main/res/drawable/ic_launcher_foreground.xml` 里用 `<group>` 把 512 画布缩到 108 自适应画布，缩放系数 `0.1746 = 32.2 / 184.4`（184.4 是卡角到中心的距离，32.2 留在 66dp 可见圆里）。**改形状要两边一起改**，别在启动图标里另画一套。

## 颜色

| 角色 | 色值 | 来源 |
| --- | --- | --- |
| 品牌绿（主底 / 深色版卡） | `#699973` / `#89CC97` | 应用内强调色 `AccentLight` / `AccentDark` |
| 卡白 | `#FCFCFC` | 应用内 `SurfaceLight` |
| 墨（箭头 / 深色版底） | `#131313` | 应用内 `TextPrimaryLight` |

绿底 + 白卡 + 墨箭头是固定搭配，不要换成语义不同的第三种颜色。需要单色时走 `simlet-icon-mono.svg`，用 `currentColor` 涂。

## 红线

- 不加投影、渐变、描边外发光、圆角外发光——这两个形状本身就够了
- 不拉伸、不斜切、不给箭头换方向；只允许整体等比缩放
- 主图标四周留白不小于卡宽的 18%；嫌挤就用 `simlet-avatar.svg`，别自己裁
- 别把卡画成正方形：斜切角是这张图唯一的「这是 SIM」的线索
- 别往卡心放图钉、地球、旗子这类自带类别的符号——放什么就被读成什么
