# Vendored icons — Reicon

本目录（`dev/reicon/`）下的 `ImageVector` 源码由上游生成器自动产出，**不要手工编辑**。
重新生成：`python tools/gen-icons.py`（图标清单与上游提交号都在该脚本里）。

- 来源项目：[Reicon](https://reicon.dev) · [dqev/reicon](https://github.com/dqev/reicon)
- 钉住的提交：`fe6975391b80c808c25d98b2a21081cf180482f9`（2026-10-25）
- 生成器：`packages/reicon-compose/tool/build_kotlin.py`
- 许可：MIT
- 收录范围：仅本项目实际用到的图标子集，非上游整包（上游共 2682 个）
